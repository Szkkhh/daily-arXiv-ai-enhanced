### [1] [PriMobiBench: Characterizing Visual Privacy Leakage in VLM-Driven Mobile GUI Agents](https://arxiv.org/abs/2609.13873)
*Qihang Cen,Tianshuo Cong,Da Song,Xinlei He,Jiaxing Song,Ke Xu,Qi Li*

Main category: cs.CR

TL;DR: 该工作提出PriMobiBench和MobiLeak，用于评测移动GUI智能体的视觉隐私风险，发现当前VLM在敏感信息泄露与用户画像推断上都存在显著风险，并验证了简单遮蔽策略具有一定缓解效果。


<details>
  <summary>Details</summary>
Motivation: 现有移动GUI智能体依赖VLM解析截图流，但会带来隐私泄露和用户画像风险；由于缺乏标准化基准，难以在真实工作流中量化这些风险，因此需要建立系统化评测框架。

Method: 构建统一评测流水线，覆盖数据生成、智能体轨迹构造与多模型评测；同时收集16个应用的执行轨迹，整理25类隐私属性和2960个隐私实例，并提出在云端处理前对与任务无关但隐私敏感的UI元素进行遮蔽的缓解方案。

Result: 实验表明，VLM可直接提取敏感信息，最高成功率达82.5%；还可从聚合视觉证据推断用户画像，成功率约70%。所提遮蔽式缓解方法可将画像推断成功率最多降低58%，且仅带来约8%的性能损失。

Conclusion: 本文提出了首个面向截图驱动移动GUI智能体的隐私泄露评测基准PriMobiBench，并配套数据集MobiLeak，用于系统评估显式敏感信息泄漏与基于视觉证据的用户画像推断风险。

Abstract: Mobile GUI agents increasingly rely on Vision-Language Models (VLMs) to automate smartphone tasks by interpreting screenshot streams. However, this design introduces serious and underexplored privacy risks, including direct leakage of sensitive on-screen information and unintended user profiling. The absence of standardized benchmarks makes it difficult to quantify these risks in realistic mobile agent workflows. To address this gap, we propose PriMobiBench, the first benchmark for systematically evaluating privacy leakage and visual profiling in screenshot-driven mobile agents. It provides a unified pipeline for data generation, agent trajectory construction, and multi-model evaluation. We also introduce MobiLeak, a dataset of execution traces from 16 apps, covering 25 privacy attributes with 2,960 embedded privacy instances. Our results reveal substantial risks: (1) VLMs can directly extract sensitive information with up to 82.5% success rate; (2) beyond explicit leakage, they can infer user profiles from aggregated visual evidence with approximately 70% success. We further propose a mitigation that masks privacy-sensitive but task-irrelevant UI elements before cloud processing, reducing profiling success by up to 58% with only approximately 8% performance loss. Overall, our work provides the first systematic benchmark for visual privacy risks in mobile GUI agents, demonstrates that both leakage and profiling are feasible at a highly concerning level, and offers a practical direction for mitigation.

### [2] [Policy-Governed Post-Quantum Migration for Legacy Microservices Using Ephemeral Sidecar Architectures](https://arxiv.org/abs/2609.14286)
*Nirmal Kumar Jingar*

Main category: cs.CR

TL;DR: 提出PG-PQMES：一种通过临时侧车和策略治理实现后量子密码无侵入迁移的框架，目标是在不改动遗留代码的前提下降低迁移风险与停机，并提升性能与可回滚性。


<details>
  <summary>Details</summary>
Motivation: 量子计算快速发展对传统经典密码构成风险，而微服务与云原生企业系统中遗留密码原语与应用耦合紧密，直接迁移到后量子密码既复杂又具有破坏性，因此需要一种无需修改遗留代码的平滑迁移方案。

Method: 采用三层协同架构：1）Ephemeral Crypto Sidecar Layer在运行时注入密码能力；2）Policy Governance Layer集中管理迁移策略；3）Migration Safety and Observability Layer负责性能监测与自动回滚，并提出PG-EPM算法以优化性能、合规性与信任驱动迁移。

Result: 实验表明，在微服务仿真环境中，该方法可显著降低迁移时间、服务停机时间、延迟开销和回滚恢复时间，相比现有迁移策略表现更优，说明基于策略的侧车迁移具有可行性、可扩展性和企业级应用潜力。

Conclusion: 该摘要提出了一种面向云原生与微服务系统的后量子密码迁移框架PG-PQMES，通过无侵入的侧车架构、中心化策略治理以及可观测的安全回滚机制，实现对遗留应用的透明、动态、可逆迁移。

Abstract: The fast development of quantum computing represents a big risk to classical cryptography that is commonly used in cloud native and microservice based enterprise systems. Traditional cryptographic primitives are closely linked to legacy microservices and it is both intricate, hazardous, and disruptive to straight up migrate to post-quantum cryptography (PQC). In a bid to overcome these issues, this research presents a PolicyGoverned Post-Quantum Migration through Ephemeral Sidecar Architectures (PG-PQMES), a framework of dynamic and reversible migration that allows transparent adoption of PQC without any modifications in the legacy code of applications. The architecture is a combination of three coherent layers, including Ephemeral Crypto Sidecar Layer which injects the runtime cryptography, Policy Governance Layer which manages the migration centrally, and Migration Safety and Observability Layer which measures the performance and rolls back automatically. An innovative Policy-Governed Ephemeral PQ Migration (PG-EPM) algorithm is proposed to maximize the performance, compliance, and trust-based migration. In simulated environment of microservices, experimental assessment shows that the time of migration, service downtime, overheads of latency, and rollback recovery time are substantially reduced using the current migration strategies. The findings show that a sidecar-based migration strategy that is policy-based offers a viable, scalable, and enterprise-scale migration to a secure post-quantum transformation.

### [3] [ActGuard: Pre-execution Action Auditing against Indirect Prompt Injection in LLM Agents](https://arxiv.org/abs/2609.14987)
*Bingzheng Wang,Xiaoyan Gu,Wentao Wang,Xingyou Yang,Hongcheng Li,Rong Yin*

Main category: cs.CR

TL;DR: ActGuard 通过“先验对比 + 证据定位 + 局部屏蔽重生成”的方式，细粒度拦截工具调用代理中的间接提示注入攻击，既降低攻击成功率，又尽量保留任务性能。


<details>
  <summary>Details</summary>
Motivation: 现有防御主要依赖提示加固、内容过滤、预生成计划或权限约束，往往会过度过滤外部内容，或在复杂任务中难以兼顾安全性与可用性，因此需要一种能在不牺牲任务灵活性的前提下，细粒度识别间接提示注入攻击的方法。

Method: 在每一步中先预测下一动作可能使用的工具，构建不约束执行轨迹的局部工具先验；随后在执行前将候选动作与该先验对比，进行工具级对比分析与参数级证据定位；最后由验证器检查定位到的证据，仅屏蔽被确认恶意的文本片段，并在净化后的上下文中重生成动作。

Result: 实验表明，ActGuard 能将攻击成功率降低到与当前最先进防御相当的水平，同时任务效用接近无攻击场景，整体实现了较好的安全-效用权衡。

Conclusion: ActGuard 提出了一种用于工具调用型 LLM 代理的预执行动作审计框架，核心目标是在保留执行灵活性的同时，精确识别并移除真正诱发不安全动作的恶意内容。

Abstract: Large language model (LLM) agents interact with external environments through tool invocation, but tool outputs can also expose them to indirect prompt injection (IPI) attacks. Existing defenses mainly rely on prompt hardening, content filtering, pre-generated plans, or permission constraints. These approaches often struggle with complex tasks or over-sanitize external content, making it difficult to balance security and utility. The key challenge is therefore to preserve execution flexibility while precisely identifying and removing the malicious content that actually induces unsafe actions. To address this challenge, we propose ActGuard, a pre-execution action auditing framework. Rather than judging whether external content is inherently suspicious, ActGuard assesses whether it causes the current action to deviate from a locally reasonable expectation. At each step, ActGuard predicts the tools likely to be used by the upcoming action and constructs a local tool prior without constraining the execution trajectory. Before execution, it compares the candidate action against this prior and performs tool-level contrastive analysis and parameter-level evidence localization to identify deviations in tool selection and action parameters. A verifier then examines the localized evidence, masks only spans confirmed as malicious, and regenerates the action from the sanitized context. This design preserves legitimate planning flexibility while minimizing information loss from indiscriminate filtering. We evaluate ActGuard on challenging benchmarks for tool-using agents. Results show that ActGuard reduces attack success rates to a level comparable to state-of-the-art defenses while maintaining task utility close to the no-attack setting, achieving a favorable security-utility trade-off. Our code is publicly available at: https://github.com/binzhwang/ActGuard.

</details>
